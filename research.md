# Research

My research aims to make software development more reliable
by combining intelligent systems with rigorous techniques
for reasoning about program correctness.

## Trustworthy Agentic Software Engineering

My current research investigates how LLM-based software
engineering agents can use verification tools and hypotheses
about intended program behavior to find and repair bugs.

A central challenge is that detecting an unexpected behavior
does not necessarily tell us what the program was intended
to do. I am interested in agents that can formulate,
evaluate, and refine hypotheses about intended behavior,
using verification feedback to guide their decisions.

This research is supported by my DFG Walter Benjamin project
at Humboldt-Universität zu Berlin.

## Neural Bug Detection

I have investigated how machine learning models can learn
from developer mistakes to detect and repair software bugs.

This includes work on training neural bug detectors with
artificial and real-world bugs, as well as the development
of [RealiT](https://github.com/cedricrupb/nbfbaselines).

## Cooperative Software Verification

Another focus of my research is improving automated
software verification by combining and coordinating
different verification techniques.

My work includes verification tools such as
[PeSCo-CPA](https://link.springer.com/chapter/10.1007/978-3-030-17502-3_19)
and
[BubaaK-SpLit](https://link.springer.com/chapter/10.1007/978-3-031-57256-2_20).

These tools achieved third place in the ReachSafety category
at SV-COMP 2019 and second place in the SoftwareSystems
category at SV-COMP 2024, respectively.

Selected publications:
[TACAS 2019](https://link.springer.com/chapter/10.1007/978-3-030-17502-3_19) ·
[ASE 2020](https://dl.acm.org/doi/10.1145/3324884.3416633) ·
[TACAS 2024](https://link.springer.com/chapter/10.1007/978-3-031-57256-2_20)

## Learning-Based Methods and Formal Verification

I also investigate how learning-based systems and formal
verification techniques can complement each other.

The longer-term objective is to combine the flexibility
of intelligent systems with the reliability of rigorous
software analysis.

Selected publication:
[FASE 2024](https://link.springer.com/chapter/10.1007/978-3-031-57259-3_13)
